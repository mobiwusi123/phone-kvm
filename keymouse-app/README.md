# 键鼠APP

把手机变成电脑的无线键盘鼠标 —— Android 版。

> 本项目是 `phone-kvm`（Go 写的 PC 端服务 + 手机网页前端）的**移动端重写版**。
> PC 端 `phonekvm.exe` **不需要任何改动**，本 APP 直接复用它的二进制协议。

---

## 一、它是怎么工作的

```
┌─────────────┐   同一 Wi-Fi / 热点    ┌──────────────────┐
│  手机 APP    │  ──── WebSocket ───▶  │  PC: phonekvm.exe │
│ 触摸板+键盘  │   二进制键鼠事件        │  ↳ Windows API 注入│
└─────────────┘                       └──────────────────┘
```

1. 电脑上运行 `phonekvm.exe`（监听 8123 端口，随机生成一个访问密钥）
2. 电脑终端会打印**二维码**（`http://192.168.x.x:8123/<密钥>/`）
3. 手机 APP 扫这张码，解析出 IP / 端口 / 密钥，直接建立 WebSocket
4. 手机上的触摸、按键被编码成二进制帧发给电脑，电脑注入为真实键鼠输入

**不需要云服务器，不需要域名备案，没有任何中转 —— 局域网直连，延迟最低。**

## 三、打包成 APK（HBuilderX 云打包）

本机没有 Android SDK / Gradle，所以走 **HBuilderX 云打包**（不需要本地 Android 环境）。

1. 打开 **HBuilderX** → 菜单 `文件 → 打开目录` → 选择 `D:\键鼠APP`
2. 首次打开若提示"该项目是一个 uni-app 项目"，确认即可
3. 菜单 `工具 → 登录`，用 **DCloud 账号**登录（免费注册：https://dev.dcloud.net.cn）
4. 双击打开 `manifest.json` → 「基础配置」页签 → 点 **「重新获取」** 生成 uni-app 应用标识（AppID）
   - 这一步必做，否则云打包会提示缺少 AppID
   - 应用图标已指向 `static/logo.png`，可不动
5. 菜单 `发行 → 原生App-云打包`
   - 平台勾选 **Android**
   - 证书：选 **「使用云端证书」**（免自己生成 keystore，最省事）
   - 打包方式：**正式版**
6. 点「打包」，等 3～10 分钟，完成后 HBuilderX 会给出 **APK 下载链接**，下载后传到手机安装

> **关于启动广告（重要）**
>
> 云打包出的 APK 默认可能带一个 DCloud 的「快捷广告」开屏页（或悬浮红包）。
> 它**不是本项目代码里的东西**，也不是你写了广告——它来自 DCloud 的 uni-ad 广告联盟，
> 由**云端开关**控制，云打包时被写进包里（包内会出现 `DCLOUD_AD_ID`）。
>
> **这个广告可以免费关掉**，三步缺一不可：
>
> 1. 用 HBuilderX 登录的同一账号登录 uni-ad 后台 <https://uniad.dcloud.net.cn>
>    →「广告设置」→ 找到你的应用 →「App 广告」下把 **「DCloud 快捷广告」**
>    及其子项（开屏广告 / 悬浮红包 / uniMP 激励视频等）**全部关闭**
> 2. 回到 HBuilderX 重新云打包，在打包界面**取消勾选「DCloud 快捷广告」**
>    （如果这一项是灰色不可取消，说明第 1 步没关干净，或账号不是应用所有者）
> 3. **必须重新出包才生效** —— 只在后台关掉而不重新打包，旧包里仍然带着广告配置
>
> 两个正常现象：后台改动到云端生效约有 20 分钟延迟；客户端可能已缓存一条广告，
> 首次启动仍会显示一次。
>
> 若坚持一个广告字节都不要，只有两条路：买 DCloud 商业授权，或者走**本地离线打包**
> （用 DCloud 的 Android 离线打包 SDK + Android Studio 自己编译，需搭几个 G 的环境）。

## 四、使用步骤

1. 电脑上双击运行 `phonekvm.exe`（首次运行 Windows 会弹防火墙提示，**必须点「允许」**）
2. 手机连上与电脑**同一个 Wi-Fi**（或连电脑开的热点）
3. 打开 APP → 点「**扫码连接**」，扫电脑窗口里的二维码
   - 扫完自动填入地址和密钥并跳转
   - 也可以手动输入，例如 `192.168.1.5:8123` + 密钥
   - 连过的地址会存进「最近连接」，下次点一下就行

## 五、操作方式

### 触摸板

| 手势 | 效果 |
|---|---|
| 单指滑动 | 移动光标 |
| 单指轻点 | 左键单击 |
| 轻点后快速双击并按住滑动 | 按住左键拖拽（同笔记本触摸板习惯） |
| 双指轻点 | 右键单击 |
| 双指滑动 | 滚轮上下 / 左右滚动 |

### 鼠标键

底部「左键 / 中键 / 右键」支持**按住不放**（拖拽、框选），「回中」把光标拉回主屏中央。

### 键盘面板

- 顶栏点「键盘」展开
- **Ctrl / Alt / Shift / Win** 是**粘滞键**：点一下点亮，再点任意键就发出 `Ctrl+X` 组合，随后自动弹起
- 第二行是常用键（Esc / Tab / Enter / 退格 / Del / 空格）、第三行可横向滑动（方向键 / Home / End / PgUp / PgDn / F1～F12）
- 底部输入框：**支持中文输入法**，打完字点「发送」或按回车，整段文本一次性送到电脑
  - （设计上只在按「发送」时读取内容，避免拼音组字过程中的字母被误发）

### 设置（顶栏「设置」）

| 项 | 说明 |
|---|---|
| 指针灵敏度 | 手指滑动 1 像素 → 光标移动几像素，默认 1.5 |
| 滚动速度 | 双指滚动的倍率，默认 1.4 |
| 自然滚动 | 手指下滑 = 页面向上滚（同手机习惯），默认开 |
| 保持屏幕常亮 | 操控时不让手机息屏，默认开 |

顶栏还会显示**连接状态**和 **RTT 延迟**（每 2 秒一次心跳测量）。

## 六、常见问题

**连不上 / 一直"连接中…"**
- 确认手机和电脑在同一网段（同一 Wi-Fi，或手机连的是电脑热点）
- 确认电脑上 `phonekvm.exe` 正在运行、没关窗口
- 电脑防火墙拦截了：到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里勾选，或临时关闭防火墙测试
- 电脑开了 VPN（Radmin / Tailscale 等）会导致地址选错，可加 `-allow-vpn` 参数运行

**扫码没反应**
- 首次使用要授权相机权限（手机设置 → 应用 → 键鼠APP → 权限）
- 也可以在连接页手动输入地址

**电脑端退出后**
- APP 会显示"电脑端已退出"，重新运行 `phonekvm.exe` 后会自动重连

**侧边返回手势冲突**
- 全面屏手势导航下，从屏幕左右边缘往内滑会触发系统返回。触摸板操作尽量避开最边缘 20px。可在手机设置里把导航方式改成"三键导航"。

**打包时报"缺少 AppID"**
- 见第三节第 4 步，先在 `manifest.json` 里重新获取应用标识。

## 七、协议速查（与 `server.go` 严格一致，小端序）

手机 → 电脑：

| 类型 | 载荷 |
|---|---|
| `0x01` move | int16 dx, int16 dy |
| `0x02` button | uint8 键位(1左 2右 3中 4后退 5前进), uint8 1按下 0抬起 |
| `0x03` wheel | int16 垂直, int16 水平（单位 1/120 格） |
| `0x04` key | uint16 虚拟键码, uint8 1按下 0抬起 |
| `0x05` text | uint16 字节数 + UTF-8 正文 |
| `0x06` ping | uint32 序号（原样回 pong） |
| `0x08` center | 无载荷（光标回主屏中央） |
| `0x09` query | 无载荷（查询光标 → 回 `0x0A`） |

电脑 → 手机：`0x07` pong（回 4 字节）、`0x0A` cursor（int32 x, int32 y）

WebSocket 地址：`ws://<IP>:<端口>/<密钥>/ws`
